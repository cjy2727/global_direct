# 제품 요구사항

## 목표

전 세계 고객이 전 세계 쇼핑몰 상품 URL을 입력하고 원하는 국가로 구매대행을 신청할 수 있게 한다. 구매 국가·배송 국가·화면 언어·상품 원화폐·견적 통화·결제 통화는 서로 독립적인 개념이다. 국가 선택 가능 여부와 실제 구매·배송 지원 여부를 구분한다.

## MVP 사용자 흐름

1. 고객이 전 세계 쇼핑몰 URL을 입력한다.
2. 시스템이 상품 제목, 이미지, 가격, 판매처를 수집한다.
3. 수집 실패 시 운영자 수동 견적으로 전환한다.
4. 고객이 옵션, 수량, 요청사항을 입력한다.
5. 구매국·배송국·견적 통화와 배송지를 선택한다. 확인된 상품 소계를 안내하고 대행비·배송비·세금·총액은 확정 전까지 미확인 상태로 표시한다.
6. 고객이 구매대행 신청을 제출하면 검토 대기 상태로 저장한다.
7. 운영자가 주문 검토, 현지 주문, 창고 입고, 검수, 국제 발송을 처리한다.
8. 고객은 주문 번호로 진행 상황을 확인한다.

## 주문 상태

`review_pending → confirmed → local_ordered → warehouse_received → inspected → international_shipping → customs → domestic_shipping → delivered`

예외 상태: `manual_quote`, `cancelled`, `refund_requested`, `refunded`, `blocked_item`.

현지 주문 이후 고객 변심 취소는 별도 문의 대상으로 처리한다. 금지품목은 견적 단계에서 차단하고, 자동 판별이 불확실하면 수동 검토로 보낸다.

## MVP 범위

- URL 유효성 및 허용 도메인 검사
- 상품 수집 작업 큐 구조
- Playwright 기반 상품명·이미지·가격·옵션 자동 분석
- 분석 결과를 저장한 상품 상세 페이지
- 옵션·수량·요청사항과 장바구니
- 주문 생성과 상태 이력
- 고객용 주문 조회
- 관리자 주문 큐와 허용된 상태 전이
- 모바일 대응 UI
- 다국어 확장을 위한 문구 분리 기반

## 후속 단계

- 쇼핑몰별 수집 어댑터
- 회원가입과 주소록, 개인통관 정보 암호화
- 창고 바코드, 검수 사진, 합포장
- 배송사 API와 LINE/이메일 알림
- 환율 공급자, 관세 룰 엔진, 쿠폰
- 고객지원 티켓과 보상 정책

## 구현된 2차 범위

- 세션 기반 회원가입·로그인과 안전한 비밀번호 해시
- 로그인 고객의 주문 생성 및 내 주문 조회
- 주문 시 국가 코드를 포함한 배송지 스냅샷 보존
- 창고 검수 결과와 국제배송 송장 데이터 구조
- 상품수집과 배송사 연동을 교체 가능한 PHP 인터페이스로 분리

## 글로벌 기반 구현 범위

- 구매국은 모를 경우 미확인으로 저장하며 도메인이나 통화로 추측하지 않는다.
- 배송국은 필수이고 국가별 기본 필수 주소 항목을 검사한다. 상세 주소와 배송 경로의 유효성은 운영 검토 대상이다.
- 동일 통화의 상품 소계와 설정된 KRW/JPY/USD 교차 환율을 계산한다. 나머지 환율은 수동 견적 대상이다.
- 주문별 원화폐·단가·수량·견적 통화·환율·시각과 요청사항을 보존한다.
- 기존 주문의 국가와 통화를 추정하여 덮어쓰지 않는다. 기존 JPY 금액은 이전 주문 형식으로 표시한다.
- 현재 화면 언어는 한국어이며 번역 UI, 실시간 환율, 결제 통화 선택, 국가별 배송 요율과 세금 계산, 운영자 견적 확정은 후속 구현이다.
- 신규 견적의 `manual_quote`는 비용 검토 상태이며 주문 처리 상태 `review_pending`과 별개다.
